# UDP Test

Separate test app for UDP + SlowDNS only (com.parami.udptest): DNSTT SlowDNS tunnel, Hysteria/WireGuard UDP via the engine, ZIVPN UDP kind recognition with an honest not-connectable message. No pool, no publish, no updater — manual install from releases.

Releases carry UdpTest.apk; version.json on main records the current version.
